# Glossary (for review)

Updated: 2026-09-12. These are project-specific definitions for consistent production instructions, not the only valid definitions of these terms. Consultation is not mandatory while writing.

| Preferred term | Meaning in this project | Distinguish from |
| --- | --- | --- |
| Panel script | A written plan specifying each panel's art, dialogue, and purpose | A synopsis |
| Thumbnails | A comic plan including panel divisions and character/text placement; also called a rough storyboard or manga name | Finished pages |
| Panel | One visual unit within a page | Not necessarily equivalent to one film shot |
| Shot | Presentation through camera position and framing | Deciding how to divide continuous movement into still images |
| Scene | A unit organized by time, place, and dramatic purpose | A page boundary |
| Beat | One change in emotion or action | A fixed number of seconds |
| Wide shot / long shot | Framing that shows characters in relation to their surroundings | A background-only panel |
| Close-up | Framing that enlarges an expression or part of the body | Not necessarily a shot of a face |
| Silent panel | A panel without dialogue or internal monologue | Specify separately whether it includes sound effects or ambient sounds |
| Pause / breathing room | Space for readers to register emotion, time, or hesitation | Not determined solely by the amount of blank space |
| Reading flow | Placement that guides readers through panels, text, and characters | The direction a character is looking |
| Balloon | A shape containing speech or inner thoughts | Sound effects placed directly on the art |
| Burst balloon | A shape outlined by radiating spikes | Define its use for inner thoughts, shock, or other effects in the project |
| Internal monologue | A character's inner narration | Objective narration |
| Page turn | A reveal created by opening the next page | Requires a different design from vertical scrolling |
| Bleed | Art extending to the trimmed edge | A character extending beyond a panel border |
| Theatrical flair | Expressive spectacle through exaggeration, composition, or a dramatic pose | An accidental drawing error |
| Continuity | Character and world rules remain consistent unless a change is intentional | Intentional changes through emotion or growth |
| Character sheet | Reference for a character's appearance and stable features | An instruction to freeze every expression |
| seed | The initial random state used in generation | A character ID or guarantee of exact reproduction |
| LoRA | Lightweight adaptation data added to a trained model | Not interchangeable across all models |

For visual design rationale, see `immersion-and-cinema.md`; for lettering, see `japanese-manga-readability.md` (the stable filename now contains US English guidance); for sources on generation terminology, see `ai-production.md`. Add usage examples, aliases, and common confusions when introducing a term. Define project-specific terms in `docs/story/TERMS.md`; do not mechanically standardize variations that express a character's voice.
