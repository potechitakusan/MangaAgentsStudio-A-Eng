# Sources and Scope for Comic, Film, and Screenwriting Guidance

Material retrieved: 2026-09-13. Public repository and usage notice rechecked: 2026-09-13.

The principal film/screenwriting reference is [jtydhr88/screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills), consulted for story, character goals/conflict, dialogue, scene change, visual information, and serial structure.

Comic guidance is organized as production suggestions for decisions about still images, lettering, panels, and pages. The complete screenwriting skill set, book/script excerpts, and verbatim translations are not bundled. Not every cited book/film was directly checked, and the original authors' claims are not presented as independently verified against primary sources.

Normally use the bundled comic guidance; consult only the relevant source below when terminology or scope needs checking. Do not make fixed conversions from film duration/screenplay page ratios to panel counts, or turn contracts, submission formats, and industry regulations into standard comic-production steps.

The source contains a personal-study usage notice: [参照元の利用条件](https://github.com/jtydhr88/screenwriting-skills#conventions), checked 2026-09-13. The kit's MIT License does not apply to that source material.
