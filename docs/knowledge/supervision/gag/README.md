Included in version 0.3.1. Updated: 2026-09-17. Use for developing written scripts and thumbnails and reviewing PNG previews.

| Need | Reference |
| --- | --- |

| Establish the mismatch through words, objects, and actions | [Aligning expectations and evidence](know-how.md) |
| Develop ideas and review repetition and recipient reactions | [Idea development and supervision](design-and-review.md) |
| Check character, causality, reading order, information, and endings | [Common knowledge](../../review-workflow.md#common-knowledge) |

The basic sequence is **premise → expectation → mismatch → evidence for understanding and the response**. This is an order for examining relationships among information, not a prescribed panel count or layout. Select only the items needed and build humor from character desires and established settings.

The structures and production proposals here do not guarantee laughter in every work. Distinguish comprehensibility from funniness, and separate facts visible in an image, interpretive hypotheses, and reactions not yet observed.
