# Comic framing, space, and continuity review

This skill is bundled with the manga project. Paths below are relative to the working project root. When testing the original in the distribution kit, use `templates/manga-project/config/review-profiles.json` for emphasis settings.

Confirm the target scene, intent, and input (synopsis / text storyboard / rough storyboard / manuscript / reference art), then read effective emphasis under `docs/knowledge/review-workflow.md`. The primary perspective is `cinema`. For judgments, consult relevant sections of `docs/knowledge/immersion-and-cinema.md`.

Check spatial relationships, who looks at what, and actions/reactions across the panel sequence. Explain what information wide, medium, and close shots give readers, and whether changes in direction or viewpoint cause confusion. When adapting continuous film action, account for omission, simultaneous visibility of panels, page turns, and reading speed; do not require one shot per panel. At minimum, propose improved transitions for problem areas.

Include the location, observation, hypothesized reader effect, severity, proposed improvement, and effect that would be lost. For consultation, give proposals and reasons for choosing them. In reviews, honestly record "no issue" or "cannot judge" when appropriate. The main agent integrates final decisions and saves them in `docs/reviews/`. Record reusable feedback in `docs/feedback/` only when the user asks to retain it; otherwise do not ask whether to record it.

Normally review the comic panel sequence and rough storyboard directly, using relevant sections of `docs/knowledge/manga/02-visual-direction.md` and `docs/knowledge/manga/04-scene-dialogue-props.md`. Map shots to panels only when film reference material exists. Consult `screenwriting-skills` only as needed to verify sources; do not import language requirements from those source materials.
