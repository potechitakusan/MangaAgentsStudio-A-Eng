## Text/rough storyboard proposals

1. Confirm main effect and character goals, then examine the current proposal under the selected item's applicability conditions. Check characters, clues, and before/after changes that carry the effect. Do not determine the effect from a gaze or silence alone or apply every theme indiscriminately.
2. Preserve desires, knowledge, actions, and established facts. Do not uniformly shorten/intensify comic responses or increase/decrease proximity/exposure. Allure supervision must not add nudity/sex or invent affection or an established relationship.
3. Return only needed proposals. For each, include location, reader-facing clues, expected effect, and possible lost effects.
4. When combining themes, prioritize the main effect. Check that revisions do not cancel sincere emotion, relationship choices, or setting conditions. Do not change ability, knowledge, or responsibility for emphasis or infer attraction, forgiveness, resumed relationships, or recovery from a single reaction. If no issue exists, propose leaving it unchanged.

## Preview proposals

1. Actually open the PNG or other target and verify version/page/location. Without viewing it, limit conclusions to the storyboard.
2. Separate observed facts, interpretation hypotheses, and improvements. Unmeasured reader reactions such as laughter, attraction, fear, or sadness are not facts.
3. Address the cause of unclear intent. Distinguish local dialogue/evidence/reaction fixes from changes to the premise.
4. Return improvements and effects to preserve; after adoption by the main agent, present and inspect the affected location again.

## Return

- Target, stage, and scope actually inspected.
- Main effect and kit documents/items used.
- Observation / interpretation hypothesis / change / expected effect and tradeoff.
- Conflicts, unverified points, and acceptance decisions for the main agent.

Use project `docs/reviews/SUPERVISION.md` if needed. Do not add review weights or evaluation criteria. Do not contribute knowledge upstream from ordinary production without a request.
