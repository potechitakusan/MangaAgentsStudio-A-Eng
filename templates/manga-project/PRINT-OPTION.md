# Options when printing is selected

**Disabled by default.** Online PNG production does not require this form or print answers. Read only if printing is requested. Conversational instructions prevail; handle later changes under [Applying settings](docs/knowledge/project-options.md).

| Item | Current setting | Selection and checks |
| --- | --- | --- |
| Print output | Disabled | Enable to consider following items. File presence alone does not enable |
| Printer/product | Unspecified | Printer, trim size, binding, interior versus cover |
| Official specification source/date | Unverified | Current printer URL and check date |
| Trim dimensions | Unspecified | State units; Web pixels are not a paper format |
| Bleed/full manuscript dimensions | Unspecified | Follow printer requirements |
| Crop marks | Unspecified | Required presence/placement per printer |
| Basic frame, binding gutter, fore edge | Unspecified | Binding side, left/right pages, margins; US English normally binds on the left |
| Resolution/pixels | Unspecified | Compare physical size, required dpi, actual source detail |
| Color/profile/tone mode | Unspecified | RGB, CMYK, grayscale, bilevel, etc. per printer |
| Submission format/page order | Unspecified | Extension, cover/interior separation, spreads/single pages |
| Print-data validation | Not performed | Clipping, bleed, color, actual-size proof where needed |

Clarify missing specifications only when enabled. Continue independent Web planning/storyboard work while awaiting answers. Preserve Web originals/PNGs; prepare print output separately with its own specifications. Changing dpi metadata or enlarging an image does not establish print quality.

The basic frame guides placement; the trim frame marks cutting. Web basic/text-safe frames do not guarantee protection against trimming/binding loss. If PSD requested, preserve creation/reopening after PNG revision confirmation. Print settings alone do not request PSD creation or transmission to a printer.
