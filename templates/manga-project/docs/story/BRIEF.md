# Intent of the work

Characters, synopsis, and page count are sufficient to start. Codex organizes the following from the request and provisionally decides unspecified details. Do not make every field mandatory user input.

- Requested characters, settings, references:
- Requested synopsis:
- Wording fixed verbatim by the request (dialogue / in-world text):
- Voice examples, not copied directly into dialogue ([Character-specific language](../knowledge/manga/04-scene-dialogue-props.md#d10)):
- Readers:
- Expected page/episode count:
- Left-bound, left-to-right page comic / other format:
- Genre/style:
- Emotion after reading:
- Protagonist's desire / what is missing:
- Obstacles/conflict:
- What changes by the ending:
- Essential scenes:
- Constraints / expressions to avoid:
- Current deliverables/completion criteria:

Review/revise PNG previews first; after no revisions remain, proceed to PSD. If creation was not instructed, ask and wait; do not re-ask existing instructions. Requested PSDs require creation, validation, and handoff. Humans finish in CLIP STUDIO PAINT before external publication.

- PNG preview pages:
- PSD instruction: none (record content/scope if instructed).
- PSD pages/layer policy:
- Requested generation dimensions / actual dimensions: fit the tool / check after generation.
- Environment/model/subscription, steps/sample count/extras/cost conditions: record when used. Opus follows [No-Anlas conditions](../knowledge/ai-production.md#novelai-opus).
- Frame-layout dimensions: actual full-page generation size; choose destination-page size for panel generation.
- Final PNG dimensions: same as layout; record conversion method if different.
- Web color/display: white, RGB/sRGB, single pages unless overridden.
- Basic frame/text-safe area: `config/page-layout.json`; consult `PRINT-OPTION.md` only if printing selected.
- Human finishing:
- CBZ: do not create (record scope only on explicit request).
